# Project Docs for Obsidian

The Obsidian half of [Project Docs](https://github.com/coreyx/vscode-project-docs), which keeps a repo's docs folder and a folder in your vault in sync on the same machine. Syncing is done by the Project Docs VS Code extension or its command line. This plugin covers what happens inside Obsidian: private notes, sync rules, sync status and decoded views.

It's in development. The full guide comes with the first release.
